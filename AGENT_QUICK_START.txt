## Installation Options

### Option 1: Python Library (Easiest for testing)

1. Install the agent:
   pip install -e .

2. Set environment variables:
   $env:INTERPOSE_API_KEY="89f22d5f-0aaf-40b9-a127-1c3af3c4a4ea"
   $env:INTERPOSE_BACKEND_URL="https://vs6hlg109c.execute-api.us-east-1.amazonaws.com/prod"

3. Use in your Python code:
   ```python
   from interpose.agent.agent import InterposeAgent
   
   # Initialize agent
   agent = InterposeAgent(
       api_key="89f22d5f-0aaf-40b9-a127-1c3af3c4a4ea",
       backend_url="https://vs6hlg109c.execute-api.us-east-1.amazonaws.com/prod"
   )
   
   # Now make AI API calls - they will be monitored
   import requests
   response = requests.post(
       "https://api.openai.com/v1/chat/completions",
       headers={"Authorization": "Bearer YOUR_OPENAI_KEY"},
       json={
           "model": "gpt-4",
           "messages": [{"role": "user", "content": "What do you know about me?"}]
       }
   )
   ```

## How It Works

1. The agent intercepts HTTP requests to AI services (OpenAI, Anthropic, etc.)
2. It extracts:
   - What data sources are being accessed
   - What sensitive information is being sent
   - Risk scores based on the data
3. Logs are sent to your dashboard in real-time
4. You can see exactly what ChatGPT (or any AI) knows about you
